# IT-Resource Management (Phase 2)

Planned. This module will hold the Remotify IT-resource management part: Firebase backend, PC client (Windows 10/11 lab PCs), admin dashboard, endpoint and energy control, security log collection, and sensor integration that updates per-item equipment status (1 = working, 0 = faulty).

Work starts after Phase 1 ([`../academic-scheduling/`](../academic-scheduling/)) is signed off. See [`../docs/TIMELINE.md`](../docs/TIMELINE.md).
